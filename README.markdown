# BlogVibes

## Overview
BlogVibes is a dynamic blogging platform built to provide a seamless experience for creating, editing, deleting, and viewing blog posts in real-time. This application combines robust backend and frontend technologies to deliver an efficient and user-friendly interface for blog management and interaction.

## Tech Stack
- **Backend:** Built using Node.js and Express.js for efficient server-side handling and API management.
- **Database:** Utilizes MongoDB to store blog posts and user data securely and scalably.
- **Frontend:** Crafted with HTML, CSS, and EJS for dynamic templating, enabling a responsive and interactive user experience.

## Features
- **Create Posts:** Users can easily compose and publish new blog posts.
- **Edit Posts:** Modify existing posts with a straightforward editing interface.
- **Delete Posts:** Remove unwanted posts effortlessly.
- **Real-Time Interaction:** View and manage blogs in real-time with a seamless, dynamic interface.
